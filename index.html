I-enable ang Tax/VAT sa Checkout

Kapag na-enable, lalabas ang tax row sa Cart at ma-apply ito sa Checkout gamit ang default rate na ito (puwede pa ring i-adjust per-transaction sa cart).

I-enable ang Auto-logout dahil sa Inactivity

Para sa security, awtomatikong mag-lo-logout ang naka-login na user (cashier/manager) kapag walang mouse, keyboard, o touch activity sa loob ng itinakdang oras.

I-export ang BUONG data (Inventory, Sales, Users, Categories, atbp.) bilang isang JSON file. Gawin ito bago mag-reset ng browser storage o mag-switch ng device.

  1. Enable Anonymous Authentication:
    Pumunta sa Firebase Console > Authentication > Sign-in method > I-click ang Anonymous at i-toggle ang Enable.
  2. Set Firestore Rules (Allow Read/Write):
    Pumunta sa Firestore Database > Tab na Rules > Palitan ng: allow read, write: if true; at i-click ang Publish.
  3. Add Authorized Domain (Kung kailangan):
    Pumunta sa Authentication > Settings > Authorized domains > I-add ang website domain kung saan mo binuo ang POS.
